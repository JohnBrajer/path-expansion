# Path Expansion

**John Brajer — decision and search mechanism**

## Principle

An action or search branch can have value because of the **future possibility space it opens**, even when its immediate payoff is modest.

## Question

> If this action succeeds, what desirable states become reachable that were not reachable before?

## Decision use

Immediate utility alone can underprice actions such as:

- learning a transferable skill
- meeting a highly connected person
- building reusable infrastructure
- obtaining information that resolves several uncertainties
- creating an asset that supports multiple downstream projects

## Search use

A branch can earn additional compute when exploring it is expected to expose a valuable region of possibility space.

## Distinction

Path Expansion is not simply novelty.

A novel action that unlocks nothing has low path expansion. A familiar action that opens many valuable future branches can have high path expansion.
